# 金价实时监控与智能分析系统 - 需求文档

## 1. 项目概述

### 1.1 项目背景
黄金作为重要的避险资产，其价格波动受多种因素影响（地缘政治、美元走势、通胀预期等）。本项目旨在构建一个实时监控金价并利用大模型进行智能分析的系统。

### 1.2 项目目标
- 实时获取并展示黄金价格数据
- 当价格出现显著波动时自动触发告警
- 调用大模型 API 分析价格波动的可能原因
- 提供历史数据查询与趋势可视化

---

## 2. 功能需求

### 2.1 数据采集模块

| 功能项 | 描述 |
|--------|------|
| 实时金价获取 | 通过第三方 API 获取实时国际金价（XAU/USD） |
| 数据源支持 | 支持多数据源切换（如 GoldAPI、MetalpriceAPI 等） |
| 采集频率 | 可配置，默认每 30 秒采集一次 |
| 数据存储 | 将历史价格数据持久化存储（SQLite/PostgreSQL） |

### 2.2 价格监控与告警模块

| 功能项 | 描述 |
|--------|------|
| 阈值告警 | 价格突破设定的上限/下限时触发告警 |
| 波动告警 | 短时间内涨跌幅超过阈值（如 1%）时触发 |
| 告警方式 | 支持多种通知渠道：邮件、微信、钉钉、Telegram |
| 告警记录 | 记录所有告警历史，支持查询 |

### 2.3 大模型分析模块

| 功能项 | 描述 |
|--------|------|
| 波动原因分析 | 调用大模型 API 分析当前金价波动的可能原因 |
| 上下文增强 | 结合当日财经新闻、美元指数等信息辅助分析 |
| 分析报告生成 | 生成结构化的分析报告（Markdown 格式） |
| 模型支持 | 支持 Claude API / OpenAI API / 国产大模型 |

### 2.4 数据展示模块

| 功能项 | 描述 |
|--------|------|
| 实时价格展示 | 显示当前金价、涨跌幅、更新时间 |
| K线图表 | 展示分钟/小时/日 K 线图 |
| 历史查询 | 支持按时间范围查询历史价格 |
| 分析报告展示 | 展示大模型生成的分析内容 |

### 2.5 价格走势图模块（参考 hjyyds.com）

| 功能项 | 描述 | 状态 |
|--------|------|------|
| 面积走势图 | 带渐变填充的价格走势曲线（青色渐变风格） | ✅ 完成 |
| 时间周期切换 | 支持 1D/7D/1M/6M/1Y/5Y 多时间维度 | ✅ 完成 |
| 单位切换 | 支持 盎司(OZ)/克(G)/公斤(KG) 单位显示 | ✅ 完成 |
| 币种切换 | 支持 USD/CNY 等多币种显示 | ✅ 完成 |
| 价格标注 | 当前价格实时标注在图表上 | ✅ 完成 |
| 响应式设计 | 适配不同屏幕尺寸 | ✅ 完成 |

### 2.6 多渠道金价对比模块

| 功能项 | 描述 | 状态 |
|--------|------|------|
| 银行金价卡片 | 展示工商银行、中国银行、建设银行等金价 | ✅ 完成 |
| 伦敦金对比 | 显示各渠道与伦敦金的价差 | ✅ 完成 |
| 汇率换算 | 美元-人民币价格换算工具 | ✅ 完成 |

### 2.7 AI 分析展示模块

| 功能项 | 描述 | 状态 |
|--------|------|------|
| 日线/分钟线切换 | 支持不同时间粒度的分析 | ✅ 完成 |
| 操作建议展示 | 突出显示 AI 操作建议 | ✅ 完成 |
| 分析结论展示 | 显示 AI 分析结论 | ✅ 完成 |
| 详细分析弹窗 | 点击查看完整分析报告 | ✅ 完成 |

## 3. 非功能需求

### 3.1 性能要求
- 数据采集延迟 < 5 秒
- 告警触发延迟 < 10 秒
- 系统支持 7×24 小时稳定运行

### 3.2 可用性要求
- 数据源故障时自动切换备用源
- 支持断线重连机制
- 提供健康检查接口

### 3.3 安全要求
- API Key 等敏感信息加密存储
- 支持 HTTPS 通信
- 日志脱敏处理

## 4. 技术选型（建议）

| 模块 | 技术方案 |
|------|----------|
| 后端语言 | Python 3.10+ |
| Web 框架 | FastAPI |
| 任务调度 | APScheduler / Celery |
| 数据库 | SQLite（开发）/ PostgreSQL（生产） |
| 缓存 | Redis（可选） |
| 前端 | Vue 3 + ECharts / 纯 CLI 模式 |
| 大模型 API | Anthropic Claude / OpenAI GPT |
| 金价数据源 | GoldAPI.io / Metals.live / 新浪财经 |

---

## 5. 数据源 API 参考

### 5.1 免费/低成本方案
- **GoldAPI.io**: 提供免费额度，支持 XAU/USD 实时报价
- **Metals.live**: 免费 API，更新频率较低
- **新浪财经**: 国内可用，数据延迟约 15 分钟

### 5.2 付费方案
- **MetalpriceAPI**: 实时数据，按请求计费
- **Oanda API**: 专业外汇数据源
